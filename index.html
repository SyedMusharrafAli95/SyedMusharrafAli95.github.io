Featured Project

SanitizationAgent

A pipeline that knows when not to decide

A LangGraph pipeline that inspects documents for PII, corrupted encodings, and low-quality or harmful text before they reach a RAG index — auto-fixing what it safely can, and escalating anything it can't to a human reviewer instead of guessing.

01
Unprocessable content

Mime-type & structure checks catch documents that can't be parsed at all.

escalates
02
Encoding repair

Detects UTF-8 / mojibake corruption and repairs it automatically with ftfy.

auto-fixed
03
Quality & harm filter

Rejects blank/repetitive text outright; an LLM flags toxicity, spam, or prompt injection.

escalates
04
PII detection

Regex catches emails; an LLM catches names. Matches are redacted automatically.

auto-fixed
05
Human review

A LangGraph interrupt pauses the graph with the exact reason attached.

approve edit reject

Sanitization is a strictly sequenced, deterministic process — every document passes the same gates in the same order. That determinism is why it's built as a state graph rather than an open-ended ReAct agent or a multi-agent setup: no wasted latency, no non-deterministic paths.
